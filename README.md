# Clarity Mentor

Premium TypeScript React Native mentoring marketplace with a complete mock-data journey from onboarding to booking and sessions.

## Setup

```bash
npm install

# iOS only (requires macOS and CocoaPods)
bundle install
cd ios && bundle exec pod install && cd ..

npx react-native run-android
# or
npx react-native run-ios
```

The repository includes native Android and iOS projects generated from the official React Native 0.76.9 template.

The app uses local mock data, so no backend configuration is needed.
